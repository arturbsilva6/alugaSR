# Backend — preparação

**Status:** módulo de API ainda não implementado. Não existe autenticação nem consulta a imóveis.

Stack aprovada: Node.js e Express. Antes de criar a aplicação Express, definir e registrar sua versão e o lockfile em um PR testado. Para o MVP, planejar separação entre `routes/`, `controllers/`, `services/`, `repositories/`, middlewares de autorização e validações.

A API pública e contratos REST estão detalhados na Documentação Mestre (seções 25–26 e 37); não improvisar endpoints, estados ou campos que revelem endereços privados. Dados sintéticos até aprovação dos gates.
