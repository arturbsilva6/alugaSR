# MVP-001 — Fundação técnica (etapa 1)

**Status:** implementação parcial em branch de trabalho; não equivale ao MVP concluído.

## Objetivo desta etapa
Criar estrutura de diretórios e scripts verificáveis para frontend HTML/CSS/JavaScript, preparar módulos futuros de backend (Node.js + Express) e banco (PostgreSQL + Prisma) e adicionar CI de sintaxe e testes de fundação.

## Versão da plataforma
Node.js 26 (Active LTS no início do desenvolvimento, novembro de 2026), via `.nvmrc`. A API Express e versões do Prisma/PostgreSQL serão definidas e fixadas antes de implementar esses módulos.

## Desenvolvimento local
1. Instale Node.js 26.
2. Execute `npm ci` na raiz (ainda sem dependências externas).
3. Execute `npm run check` para sintaxe e testes.
4. Abra `frontend/index.html` no navegador para inspecionar a página provisória. Não é uma aplicação de imóveis.

## Próximos passos do MVP-001
- Definir versões concretas de Express, PostgreSQL e Prisma com compatibilidade validada.
- Configurar a API Express e scripts de start/dev.
- Integrar serviços e camadas sem expor dados reais.
- Criar testes reais de API e iniciar migrations apenas na issue apropriada (MVP-007).

## Critérios de aceite pendentes
O MVP-001 somente poderá ser encerrado após stack instalada, execução reproduzível e CI de aplicação verificada. Os testes atuais apenas demonstram a fundação inicial. Não há login, banco, upload ou anúncios.
